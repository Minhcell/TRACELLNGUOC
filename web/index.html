Tải file 452.csv.gz (Việt Nam) từ trang Downloads của OpenCelliD. File được lưu trong máy, lần sau mở là có ngay; nạp file mới để cập nhật.

Danh sách API · thử lần lượt từ trên xuống

Khi tra, app dùng API đầu tiên đang bật; nếu API đó lỗi (sai token, hết lượt, mất mạng) hoặc không ra cell nào thì tự chuyển sang API kế tiếp. Mỗi API chỉ cho hỏi một ô ≤ 4 km², nên vùng lớn được chia nhỏ (tối đa 25 lượt mỗi API).

Cách đọc kết quả

CGI = MCC-MNC-LAC-CI (4G: TAC thay LAC, CI là ECI = eNB×256 + sector; 3G: CI = RNC×65536 + CID). Tọa độ cell trong OpenCelliD là tâm ước lượng từ các mẫu đo, không phải vị trí trạm BTS thật. Cell gần nhất chưa chắc là cell phục vụ; nhãn TRONG VÙNG nghĩa là điểm tra nằm trong bán kính phủ ước lượng của cell đó. Nên lấy vài cell đầu danh sách rồi tra xuôi lại để đối chiếu.
